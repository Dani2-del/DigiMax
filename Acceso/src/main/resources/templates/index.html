CONOCE DIGITRANS

Una plataforma modular para servicios cotidianos

Digitrans es un proyecto universitario que reúne herramientas de movilidad y servicios digitales bajo una cuenta unificada. El módulo de Acceso gestiona el registro y el inicio de sesión; desde allí, cada persona puede entrar a módulos especializados.

La plataforma conecta servicios independientes para que transporte, billetera y recargas móviles formen parte de una misma experiencia.
