Proyecto universitario · Digitrans

Movilidad y servicios digitales, conectados en una plataforma.

Digitrans reúne transporte público, billetera universal y recargas móviles en una sola experiencia. Está diseñado como un conjunto de módulos independientes que se comunican entre sí y comparten un acceso centralizado.

EXPERIENCIA DE USUARIO

Tres servicios principales

Una cuenta central da acceso a los módulos que las personas usan directamente.

MOVILIDAD

Transporte

Reúne funciones para sistemas de transporte público: perfiles SITM, tarjetas y consulta de rutas, con soporte para TransCaribe, TransMilenio y Transmetro.

TARJETA Y SALDO

Billetera universal

Administra una tarjeta Digitrans y un saldo compartido con Transporte. Las cargas de saldo se registran como operaciones simuladas.

TELEFONÍA MÓVIL

Recargas móviles

Gestiona líneas y catálogos de paquetes. Las recargas se registran en el sistema, pero no activan paquetes con operadores reales.

ASÍ ESTÁ DISEÑADO

Módulos independientes, conectados por APIs

El repositorio es un monorepo, pero cada módulo es una aplicación Spring Boot independiente. Acceso centraliza la identidad y los servicios se comunican mediante APIs HTTP.

COMPONENTES DEL SISTEMA

Qué hace cada módulo

La separación permite desarrollar y mantener las funciones de forma independiente.

Acceso de usuario

Acceso

Gestiona cuentas, autenticación, identidad central, tokens JWT y la consola global de administración.

Servicio principal

Transporte

Contiene perfiles SITM, tarjetas de transporte, rutas y funciones administrativas.

Servicio principal

Billetera

Administra la tarjeta universal, el saldo compartido con Transporte y el historial de movimientos.

Servicio principal

Recargas móviles

Gestiona catálogos, líneas y recargas simuladas, y conserva el resultado en el historial.

Integración interna

Pagos

API de prueba para iniciar y consultar pagos simulados; no conecta con bancos.

Integración interna

Correo

Servicio interno que envía correos electrónicos mediante SMTP.

Dispositivo e inventario

Lector

Registra tarjetas Digitrans RFID y consulta tarjetas vinculadas e historial de titulares. El acceso está limitado a administradores y moderadores asignados a Billetera.

Herramienta local

Orquestador

Panel de desarrollo para iniciar, detener, reiniciar y supervisar los servicios locales.
